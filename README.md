# Startup instructions/project structure
1) Create virtualenv with python 3.14 in `.venv` folder: `virtualenv -p3.13 ./.venv`
2) Run Jupyter Notebook: `./run.bat`
or
3) Activate the virtualenv (example for bash): `source ./.venv/Scripts/activate`

- Python version: 3.13
- Virtualenv location (gitignored): `.venv`
- Tmp folder (gitignored): `tmp`
