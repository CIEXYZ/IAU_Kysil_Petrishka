# Startup instructions/project structure
1) Create virtualenv with python 3.13 in `.venv` folder: `virtualenv -p3.13 ./.venv`
2) Activate the virtualenv (example for bash): `source ./.venv/Scripts/activate`
3) Install needed dependencies: `pip install -r requirements.txt`
4) Start the jupyter notebook server: `jupyter notebook`
or, after first install
1) Run Jupyter Notebook: `./run.bat`

- Python version: 3.13
- Virtualenv location (gitignored): `.venv`
- Tmp folder (gitignored): `tmp`
